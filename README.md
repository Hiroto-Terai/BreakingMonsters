# BreakingMonsters（ブレイクモンスターズ）

ホッケー × ブロック崩しのスマホ向けドットゲーム。ボールを打ち返してモンスター（敵スライム）を倒し、後ろの仲間スライムを守る。
ローグライトの「ステージモード（全100ステージ）」と、1台で遊べる「たいせん」がある。

- エンジン: Unity 6000.3.26f1（Unity 6）
- 対象: iOS（縦画面）
- 広告: Google Mobile Ads（AdMob）

## 遊び方

1. タイトルでタップ → ステージマップ（全100ステージ）
2. ステージは 3〜5 階層。各階層の敵を全滅させるとクリア
3. 階層クリアごとに「強化を3つから1つ選ぶ」（そのステージ中だけ有効）
4. 最後の階層をクリアするとステージクリア。コインがもらえる
5. コインでスキルツリーを解放・強化（ずっと有効なパッシブスキル）

負けても、それまでにクリアした階層分のコインは持ち帰れる（ローグライト）。

### 操作：振って打つ

- 指でバーを左右に動かすだけ
- ボールが当たる瞬間にバーを振っていると、振った向きにボールがカーブする
- 強く振るとスマッシュ（速い球、次に当たったモンスターに +1 ダメージ）
- 敵のバーはボールの跳ね返りを読んで先回りするが、カーブは読めない

### ステージのルール

- 仲間がボールに抜かれてやられたら、ボールは真ん中に戻って打ち直し
- 何回か打ち返すごとにモンスターが一段迫ってくる。赤い点線（防衛ライン）まで来ると仲間が食べられる
- モンスターの頭の点は残りHP。右上のマークは属性（炎・氷・雷）
- 属性モンスターを倒すと、ボールがその属性をまとう。次に当たったときに効果が出る
  - 炎：まわりのモンスターにも燃え広がる
  - 氷：敵のバーを少しの間こおらせる
  - 雷：一番近いモンスターに連鎖する
- 敵のバーには性格がある：守り型 / 狙い型（仲間を狙ってくる）/ フェイント型

### たいせん

スターシュートVSのように、キャラクターごとに打った球の個性が1つある。

| キャラ | 個性 |
|---|---|
| カーブ | 振ったときのカーブが2倍 |
| ステルス | 打った球が途中で消える |
| ビッグ | 打った球が大きくなる |

- 相手：CPU（よわい / ふつう / つよい）か、1台で2人（画面の上半分と下半分でそれぞれ操作）
- 先に相手の仲間スライム3匹を倒したほうが勝ち

### ステージの種類

| 種類 | 条件 | 内容 |
|---|---|---|
| 通常 | 下記以外 | 敵の数・硬さが番号に応じて少しずつ増える |
| ハード | 3の倍数 | 敵が多く硬い、敵バーが速い、ボールがときどき透明になる |
| ボス | 7の倍数（21・42 などはボス優先） | 最終階層に巨大ボス。左右に動きながら弾を撃つ（バーで防げる） |

階層数: 1〜33 は3階層、34〜66 は4階層、67〜100 は5階層。

### ステージ中の強化（3択）

マルチボール / パワーボール / ワイドバー / ビッグボール / なかま回復 / バリア / コインざくざく / スロー

### スキルツリー（永続）

| こうげき | まもり | サポート |
|---|---|---|
| ちからだま（攻撃力+1） | なかま+1（スライムが増える） | ひろいバー（バー幅+8%） |
| ツインボール（2個でスタート） | はじまりのバリア | きんうん（コイン+15%） |
| かいしん（10%で2倍ダメージ） | ふっかつ（1回だけ復活） | えらびなおし（3択を引き直し） |

上の段を1レベル以上にすると、下の段が解放される。

## プロジェクト構成

### シーン（`Assets/Scenes`）

| シーン | 役割 |
|---|---|
| `Title` | タイトル。どこをタップしても Menu へ |
| `Menu` | ステージマップとスキルツリー（`StageSelectScreen` が画面をコードで組み立てる） |
| `StagePlay` | プレイ画面。100ステージすべてをこの1シーンで遊ぶ（`StageRunController` がステージ番号から敵を並べる） |
| `VersusPlay` | たいせんの画面（`VersusController` が上下のバーと仲間スライムを並べる） |

### スクリプト（`Assets/Scripts`）

**ローグライトの仕組み（`Roguelite/`）**

| ファイル | 役割 |
|---|---|
| `StageDatabase` | ステージ番号から種類・階層数・敵の配置/HP・ボスの強さ・報酬を計算する（100ステージを手作業で作らない） |
| `StageRunController` | 1ステージの流れ（階層づくり→カウントダウン→プレイ→3択→次の階層→クリア/ゲームオーバー） |
| `RunState` | 挑戦中のステージの状態（ライフ・選んだ強化・獲得コイン）。ステージが終わると捨てる |
| `Progress` | 端末に保存する進行状況（所持コイン・クリア済みステージ・星・スキルレベル） |
| `Upgrades` | ステージ中の強化の一覧と、3択の抽選 |
| `SkillTree` | スキルツリーの定義（値段・前提スキル）と購入処理 |
| `Boss` / `BossBullet` / `Shield` | ボス・ボスの弾・バリア |
| `Paddle` | バー（自分・敵の両方）の動く速さを測る。「振って打つ」のカーブ・スマッシュに使う |
| `Elements` | 属性（炎・氷・雷）と、たいせんのキャラクターの種類 |
| `Versus` / `VersusController` / `VersusSetupScreen` | たいせんの設定・試合の流れ・準備画面 |
| `StageHud` / `UpgradeChoicePanel` / `StageResultPanel` | プレイ中の表示・3択画面・結果画面 |
| `StageSelectScreen` / `SkillTreeScreen` | ステージマップ・スキルツリー画面 |
| `PixelArt` / `Shapes` | ドット絵を文字の並びから作る（ボス・アイコン・コインなど）。`Shapes` に形のデータがある |
| `PixelUI` | ドット風のUI部品（枠付きパネル・ボタン・文字）をコードで作る |

**元からある部品**

| ファイル | 役割 |
|---|---|
| `BallManager` | ボールの速さ・角度の制限、バーで打ち返したときの向き・カーブ・スマッシュ、属性、残像、ハードの透明化 |
| `PlayerManager` | タッチ/マウス/キーでプレイヤーのバーを動かす（2人対戦では画面の自分の側の半分だけで操作） |
| `EnemyBarManager` | 敵のバー（コンピュータ）。跳ね返りを読んで先回りし、性格ごとに狙い打ちやフェイントをする |
| `EnemyManager` | 敵スライム（HP・属性・横歩き・迫ってくる）と仲間スライム（当たると消える） |
| `CountDown` | 3, 2, 1, GO! |
| `HitEffects` / `FloatingText` | ドットの破片・画面の揺れ・残像・振動、ポップアップ文字 |
| `OptionManager` | 一時停止/設定画面（BGM・SE の ON/OFF は端末に保存）、広告を挟んだシーン切り替え |
| `LoadScene` / `BlinkText` | タイトルのタップ開始と「Tap to Start」の点滅 |
| `ObjectFit/*` | 画面サイズに合わせて各オブジェクトの位置を決める |
| `CameraSizeUpdater` | 縦横比に合わせてカメラの映す範囲を調整 |
| `Google*Ads` / `AdsCount` | バナー広告と、3回に1回の全画面広告 |

### ドット表現について

- ゲーム内のドット1つの大きさを `PixelArt.WorldPixelSize`（0.05）にそろえている
- 破片・残像・画面の揺れ・ポップアップは、ドットの格子に合わせてカクカク動かしている
- スプライトはすべて Point フィルタ（ぼかさずに拡大）
- 文字は PixelMplus（12px の倍数のサイズで使う）

## 調整のしかた

- 難易度: `StageDatabase.GetFloor`（敵の数・HP・速さの式）
- 報酬: `StageDatabase.GetStageReward`
- 強化/スキルの効果量: `RunState` の定数、値段は `SkillTree.All`
- ドット絵の見た目: `Shapes`（1文字＝1ドット、色は `PixelArt.ColorOf`）
- ボスの絵: `Tools/PixelArt/boss.py` を実行すると陰影つきの絵とプレビュー画像（boss_a.png / boss_b.png）を作る。できた文字の並びを `Shapes` の `boss` / `boss_b` に貼る
- 敵の強さ: `EnemyBarManager.Configure`（速さ・反応・予測のぶれ・狙い）、ステージごとの強さは `StageDatabase` の `EnemyLevel`
- カーブ・スマッシュ: `BallManager` の `SpinPerPaddleSpeed` / `SmashPaddleSpeed`
