# ストア掲載文（日本向けの下書き）

## 名前

- アプリ名（30文字以内）: ブレイクモンスターズ
- App Store のサブタイトル（30文字以内）: 振って打つ！ドットのホッケー×ブロック崩し
- Google Play の簡単な説明（80文字以内）: バーを振ってカーブとスマッシュ！モンスターを倒して仲間を守る、ドットのホッケー×ブロック崩し。全100ステージ。

## 説明文

ボールを打ち返してモンスターをやっつけろ！
ホッケーとブロック崩しが合体した、ドット絵のアクションゲームです。

■ 振って打つ、かんたん操作
指でバーを左右に動かすだけ。
ボールが当たる瞬間にバーを振るとカーブ、強く振るとスマッシュ！
カーブで敵のバーをかわして、うしろのモンスターをねらおう。

■ 全100ステージのローグライト
ステージは3〜5階層。階層をクリアするたびに、3つの強化から1つを選んで強くなる。
マルチボール、パワーボール、バリア……組み合わせしだいで一気に化ける！
負けても集めたコインは持ち帰れて、スキルツリーでずっと強くなれる。

■ 迫るモンスター、考える敵
モンスターはだんだん迫ってきて、防衛ラインを越えると仲間が食べられる。
敵のバーは跳ね返りを読んで先回りしてくる。守り型・狙い型・フェイント型、性格もいろいろ。
7の倍数のステージには巨大ボスが待ちかまえる。

■ 炎・氷・雷の属性
属性モンスターを倒すと、ボールがその力をまとう。
燃え広がる炎、敵を止める氷、連鎖する雷を使いこなそう。

■ 1台で2人対戦
「たいせん」モードでは、カーブ・ステルス・ビッグの3キャラから選んで対戦。
コンピュータ相手でも、友だちと1台を上下に分けて遊んでもOK。
